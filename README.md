# 点格棋 (dots-boxes)

经典纸笔游戏「点格棋」的终端版:双方轮流在点阵之间画线,围出格子
就归自己,圈到格子可以再走一步。最后谁圈的格子多谁赢。

## 玩法

- 默认 6×6 点阵(5×5=25 个格子),甲先手。
- 每回合画一条横边或竖边:`h 行 列`(横边)或 `v 行 列`(竖边)。
- 围满 4 条边即圈到该格,归属显示为 `甲`/`乙`,并**再走一步**(链式圈地)。
- 全部边画完后数格子,多者胜。

## 用法

```bash
# 人机对战(需要终端)
python3 -m dots_boxes

# AI 对 AI 自动演示 10 局
python3 -m dots_boxes --auto --games 10 --seed 42

# 自定义棋盘与局数
python3 -m dots_boxes --auto --rows 5 --cols 7 --games 5

# 打印 AI 每一步
python3 -m dots_boxes --auto --verbose
```

示例输出(真实运行):

```
第 1/10 局: 甲 12 - 乙 13  乙胜
...
总计: 甲胜 6, 乙胜 4, 平局 0
```

棋盘渲染示例:

```
甲:3  乙:1  已画 12/60  轮到:甲
+-+-+-+-+-+
|甲| | | |
+-+-+-+-+-+
   | | | |
+ + + + + +
```

## AI 说明

贪心 + 链感知两层策略:

1. **必圈格**:有能圈到格子的走法就走(圈得多的优先);
2. **链感知**:否则评估每手会"送"给对手的链有多大(走完后恰好
   3 条边的格子连成的团),选择送链最小的一手,尽量不送免费格子。

这是点格棋经典"控链"思想的简化版:完整的最优打法(loony 弃链)
没有实现,两个相同 AI 对打基本是均势(10 局约 6:4)。

## 诚实局限

- AI 只是贪心+链感知,不会做长链规划,熟悉规则的人类通常能赢。
- 文本回合制,无悔棋、无存档、无图形界面。
- 链大小评估是走完一步后的静态分析,不是完整的前瞻搜索。
- Python 3.10+,仅标准库。
